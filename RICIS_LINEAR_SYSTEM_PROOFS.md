# Доказательство системы линейных уравнений RICIS

## Назначение

Двухпеременный overload `Prove` принимает систему из двух отложенных `Expression<Func<double,double,bool>>`, ограничения области, тезис о координате и `StringBuilder`. Он строит **символический вывод** системы, не компилируя и не исполняя входные уравнения либо ограничения.

```csharp
Expression<Func<double, double, bool>>[] equations =
[
    (x, y) => x + y == 5.0,
    (x, y) => x - y == 1.0,
];
Expression<Func<double, double, bool>>[] constraints =
[
    (x, y) => x >= 0.0 && y >= 0.0,
];
Expression<Func<double, double, bool>> claim =
    (x, y) => x == 3.0;

var proof = new StringBuilder();
Expression<Func<double, double, bool>> derived =
    equations.Prove(constraints, claim, proof);
```

Результатом будет независимое expression tree `(x,y) => x == 3`, а `proof` получит шаги исключения и подстановки.

## Поддерживаемый контракт

| Элемент | Требование |
|---|---|
| Система | Ровно два уравнения вида `x+y=c`, `x−y=c`, `y+x=c` или `y−x=c`, где `c` — `double`-константа. |
| Ограничения | Любые двухпеременные boolean expression tree; они записываются в протокол, но не исполняются. |
| Тезис | Ровно `x=c` или `y=c`, где `c` — конечная `double`-константа либо константное дерево деления. |
| Невырожденность | Детерминант извлечённой системы не равен нулю. |
| Конечность | Обе правые части, константа тезиса и результат формулы Крамера должны быть конечными `double`; не-конечность и overflow отклоняются до записи ложного доказательства. |
| Рациональная форма | Если правые части системы — целые `double`, ответ строится как сокращённое дерево: целый результат — `Constant`, несократимый рациональный результат — `Divide(Constant(n), Constant(d))`. Например, `1/2` не заменяется на `0.5`. |
| Результат | Выведенное выражение требуемой координаты; противоречащий или небезопасный для конечного double-вывода тезис отклоняется исключением. |

## Последовательность вывода

Для системы `x+y=5`, `x−y=1` метод формирует четыре проверяемых expression-шагa:

| Шаг | Основание | Производное дерево |
|---|---|---|
| 1 | Линейная комбинация и исключение `y` по детерминанту | `2·x = 6` |
| 2 | Точное выделение первой координаты | `x = 3` |
| 3 | Подстановка `x=3` в первое исходное уравнение | `3+y = 5` |
| 4 | Выделение второй координаты | `y = 2` |

> Этот overload является строгим минимальным слоем для двух линейных уравнений. Он не объявляет универсальный решатель произвольных систем, не использует численное приближение и не заменяет аксиомы RICIS III.
