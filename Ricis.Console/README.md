# Ricis.Console

`Ricis.Console` — интерактивный консольный вход в RICIS. Он принимает математическую строку, строит настоящее дерево `Expression<Func<double,double>>`, запускает `RicisPhasePipeline` и показывает исходную и производную лямбды.

> Ввод **не компилируется как C#** и не может вызвать произвольный метод. Консоль использует ограниченный рекурсивный parser с белым списком операций и функций.

## Запуск

Из корня решения:

```bash
dotnet run --project Ricis.Console/Ricis.Console.csproj -c Release
```

Одно выражение без входа в интерактивный режим:

```bash
dotnet run --project Ricis.Console/Ricis.Console.csproj -c Release -- --expr "x => (x*x - 9)/(x - 3)"
```

Проверить встроенные сценарии парсинга:

```bash
dotnet run --project Ricis.Console/Ricis.Console.csproj -c Release -- --self-test
```

Запустить пакетный каталог из **50 входных выражений** перенесённых из приложенного стресс-набора:

```bash
dotnet run --project Ricis.Console/Ricis.Console.csproj -c Release -- --all
```

Пакетный режим выводит исходное и производное RICIS-дерево каждого выражения. Ожидаемые ответы из исходного стресс-файла не используются: результат для каждого входа строит сам конвейер RICIS.

## Формат ввода

Вводится либо полная лямбда, либо одно выражение; во втором случае параметр по умолчанию — `x`.

```text
x => (x*x - 9)/(x - 3)
sin(x)/x
x => 1/(x*(x+1))
x => (exp(x)-1)/x
x => 1/(1-x^2)
x => pow(x, 3)-8
```

| Категория | Поддержка |
|---|---|
| Параметр | Один идентификатор, например `x => ...` или `t => ...` |
| Операторы | `+`, `-`, `*`, `/`, `^`, круглые скобки |
| Константы | `pi`, `e` |
| Функции | `sin`, `cos`, `tan`, `sinh`, `cosh`, `tanh`, `exp`, `log`, `log10`, `sqrt`, `abs`, `pow` |
| Варианты имени | Регистр не важен; разрешены `sin(x)` и `Math.Sin(x)` |

После каждого успешного ввода программа выводит исходное дерево, производное дерево RICIS и пробует исполнить производное выражение для точек `-2, -1, 0, 1, 2`. Если производное дерево остаётся символическим, ошибка исполнения показывается как информация, а консоль продолжает работу.

## Интерактивные команды

| Команда | Назначение |
|---|---|
| `help` | Показать поддерживаемую грамматику |
| `examples` | Показать готовые выражения |
| `selftest` | Запустить встроенные проверки parser-а |
| `all` | Запустить 50 выражений встроенного каталога |
| `exit` / `quit` | Завершить программу |

## Семантика RICIS

Консоль передаёт полную лямбду в `RicisPhasePipeline.Simplify`. Поэтому сохраняются все приоритеты ядра: сначала тождество сущности, затем структурная алгебра и остальные правила RICIS, после чего применяется классический fallback там, где RICIS не задаёт отдельного преобразования.
