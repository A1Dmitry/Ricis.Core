# Непрерывный математический сахар RICIS

> **Document version:** `0.1.0` (provisional baseline)
> **Created:** `2026-08-15`
> **Last modified:** `2026-08-15`
> **Versioning note:** increment the document version when the normative content changes.


## Назначение

`RicisContinuousExtensions` добавляет компактные операции для **непрерывных кусочно-заданных выражений**. Пакет не вводит новую аксиому RICIS и не изменяет порядок фаз. Каждая операция принимает отложенные `Expression<Func<T,T>>`, где `T : INumber<T>`, строит новое независимое конечное дерево и только затем передаёт его в обычный конвейер RICIS.

> Делегаты входных лямбд не вызываются при построении. Пределы, правило Лопиталя, численная квадратура и скрытая подстановка точек не используются.

| Операция | Символическая форма | Назначение |
|---|---|---|
| `F.Abs()` | `F < 0 ? −F : F` | Абсолютная величина `|F|` |
| `F.Min(G)` | `F > G ? G : F` | Поточечный минимум `min(F,G)` |
| `F.Max(G)` | `F > G ? F : G` | Поточечный максимум `max(F,G)` |
| `F.Clamp(L,U)` | `min(max(F,L),U)` | Непрерывная отсечка в диапазоне |
| `F.PositivePart()` | `max(F,0)` | Положительная часть `F⁺` |
| `F.NegativePart()` | `min(F,0)` | Отрицательная часть `F⁻` |
| `F.Distance(G)` | `|F−G|` | Поточечное расстояние между двумя функциями |

## Нормализация и тождества

Операнды сначала нормализуются обычным RICIS-конвейером и затем связываются с единым параметром. Поэтому `Min(F,F)` и `Max(F,F)` возвращают `F` без искусственной ветви. `Distance(F,G)` сначала строит `Difference(F,G)`, поэтому тождества L1 и структурная алгебра применяются к разности до построения абсолютной величины. В частности, отношение двух структурно одинаковых `Abs(F)` проходит приоритет L1 и возвращает типизированную единицу.

Для `Clamp` предусмотрены постоянные границы `Clamp(lower, upper)` и полностью отложенная форма `Clamp(L,U)`. При одинаковых нормализованных границах `L≡U` возвращается общая граница. Порядок границ является контрактом вызывающего кода: библиотека не вычисляет отложенные границы и не строит скрытую проверку `L≤U`.

## Точность типов

Все операции generic и не приводят `T` к `double`. В частности, тесты фиксируют точную работу `PositivePart` и `NegativePart` с большими `BigInteger`. Для встроенных беззнаковых типов `Abs(F)` возвращает `F`, а `NegativePart(F)` — типизированный ноль.

## Консоль

Для просмотра построенных деревьев и их исполнения на контрольных значениях запустите:

```bash
dotnet run --project Ricis.Console/Ricis.Console.csproj -c Release -- --continuous-demo
```

Регрессии `SUGAR01`–`SUGAR08` покрывают форму деревьев, привязку параметров, L1, постоянные и отложенные границы, generic-целочисленную точность и расстояние.
