# APP-001 — финансовая доменная библиотека

**Статус:** `В РАБОТЕ`
**Приоритет:** `Highest`
**Источник:** пользовательский backlog от 2026-08-19

## Цель

Создать отдельную .NET-библиотеку `Ricis.Finance` для финансовых событий приложения: инвойс, подтверждённое поступление, provider balance, payout, комиссии, FX snapshot, кандидат на налоговый чек и контроль порогов. Библиотека моделирует факты и политики; она не выполняет банковские переводы и не обходится без авторизованного внешнего API.

## Роли и порядок

| Роль | Результат | Статус |
|---|---|---|
| Постановка / compliance | Проверенные внешние ограничения и границы автоматизации | Выполнено |
| DDD-архитектор | Bounded contexts, aggregates, ports, инварианты и ADR | Выполнено |
| C#-разработчик | Чистое domain ядро и application services | Выполнено |
| QA | Сценарии payment → settlement → receipt candidate, payout, fee, FX и threshold | Выполнено локально: FIN01–FIN06 |
| DevOps | Сборка, тесты, CI и публикация | CI включён; публикация ожидается |

## Non-negotiable constraints

1. `Gross`, provider fee, bank fee и `Net` — отдельные денежные значения; библиотека не считает налоговую базу по net payout без внешней политики.
2. Правило 60 000 BYN — дата- и контрагент-зависимая политика, а не глобальный универсальный лимит.
3. Событие для кандидата на чек определяется политикой и подтверждённым payment/settlement фактом; payout хранится отдельно.
4. МНС и платежные провайдеры находятся за портами. Неподтверждённый публичный API не реализуется.
5. Комиссия МТБанка не хардкодится: применяется effective-dated `IBankFeeSchedule`.
6. Повторные webhook/command доставления должны быть идемпотентными по внешнему идентификатору.

## Definition of Done

Библиотека независима от `Ricis.Core`, компилируется в solution, содержит domain/application/integration contracts, воспроизводимые FIN01–FIN06 регрессии, документацию boundary и не имеет секретов, HTTP-клиентов или конкретных платёжных API в domain layer. Публикация допускается только после полного локального и GitHub CI quality gate.
