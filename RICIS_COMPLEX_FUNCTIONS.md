# Комплексные отложенные функции RICIS

## Модель

`RicisComplexFunction<T>` представляет комплексную функцию как пару независимых отложенных скалярных лямбд:

> `F = Re(F) + i·Im(F)`, где `Re(F)` и `Im(F)` имеют тип `Expression<Func<T,T>>`, а `T : INumber<T>`.

Это **не** обёртка над `System.Numerics.Complex` и не готовый численный результат. Конструктор нормализует обе компоненты обычным RICIS-конвейером и привязывает их к одному параметру expression tree. При построении ни один входной делегат не вызывается.

| API | Символическое значение |
|---|---|
| `F.AsComplex()` | `F + i·0` |
| `Re.AsComplex(Im)` | `Re + i·Im` |
| `Z.Re()` / `Z.Im()` | Соответствующая отложенная компонента |
| `Z.Conjugate()` | `Re(Z) − i·Im(Z)` |
| `Z.Add(W)` | `(a+c) + i(b+d)` |
| `Z.Subtract(W)` | `(a−c) + i(b−d)` |
| `Z.Multiply(W)` | `(ac−bd) + i(ad+bc)` |
| `Z.SquaredNorm()` | `a²+b²` |
| `Z.Norm()` | `sqrt(a²+b²)` для `double`-домена |

## Контракт RICIS

Комплексный слой является **математическим сахаром**, а не новой аксиомой. Каждая арифметическая компонента строится через уже существующие `Sum`, `Difference` и `Product`; поэтому нормализация L1, структурная алгебра SP2, generic-точность и существующие приоритеты конвейера сохраняются автоматически. Операции не строят пределы, не используют правило Лопиталя и не выполняют скрытую подстановку ключевых точек.

Квадрат нормы остаётся generic. Например, `SquaredNorm()` для `BigInteger` не переходит к `double`. Обычная евклидова `Norm()` доступна для `RicisComplexFunction<double>` и хранит явный узел `Math.Sqrt` в результирующем дереве.

## Текущие границы

Первый пакет преднамеренно не вводит комплексное деление, аргумент, экспоненту, логарифм, ветви корня, многомерные переменные или контурное интегрирование. Эти конструкции требуют отдельных нормативных контрактов, в частности правил для нулей комплексного знаменателя и выбора ветвей.

## Консоль и тесты

```bash
dotnet run --project Ricis.Console/Ricis.Console.csproj -c Release -- --complex-demo
```

Регрессии `CPLX01`–`CPLX07` проверяют подъём вещественной функции, привязку параметров, сопряжение, покомпонентные сложение и вычитание, формулу произведения, точный `BigInteger`-квадрат нормы и `double`-норму.
