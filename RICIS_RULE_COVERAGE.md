# Нормативная матрица регрессий RICIS

## Цель

Этот документ задаёт **неизменяемый контракт регрессий** для реализованного подмножества RICIS III. Каждое правило должно иметь хотя бы один изолированный тест, а правила приоритета должны дополнительно иметь тест, доказывающий, что последующая фаза не успела изменить результат.

> Приоритет конвейера: **тождество сущности** `F ≡ F → 1` → специальные правила RICIS и структурная алгебра → разрешённые константные мосты → классический fallback для не переопределённых операций.

## Обязательства тестового набора

Тесты с префиксом `RC` являются изолированными контрактными проверками соответствующего правила. Они не заменяют стресс-тесты, а фиксируют минимальную семантику правила так, чтобы локальная правка конкретной фазы не могла случайно изменить нормативный результат.

Неопределённые для RICIS пользовательские операции не становятся частью алгебраических правил автоматически. Они наследуют классическую семантику, пока не будет добавлено отдельное нормативное правило и сопутствующий тест.
