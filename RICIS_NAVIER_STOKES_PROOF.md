# RICIS proof-сценарий Навье—Стокса

## Отдельный консольный проект

`Ricis.NavierStokes.Console` — самостоятельная .NET 8-консоль, запускающая документный proof-метод:

```bash
dotnet run --project Ricis.NavierStokes.Console/Ricis.NavierStokes.Console.csproj -c Release -- --stationary-vortex
```

Она не компилирует и не вычисляет компоненты поля для получения доказательства. Консоль строит отложенные `Expression<Func<double,double,double,double,double>>`, передаёт их в `ProveNavierStokesIdentity` и выводит весь `StringBuilder`-документ.

## Сертифицируемый сценарий

| Объект | Отложенное поле |
|---|---|
| Скорость | `u(x,y,z,t)=(-y,x,0)` |
| Давление | `p(x,y,z,t)=(x²+y²)/2` |
| Вязкость | `ν=1` |

Метод строит точные expression tree для

\[
\nabla\cdot u,\quad \partial_tu,\quad (u\cdot\nabla)u,\quad \nabla p,\quad \Delta u,
\quad R=\partial_tu+(u\cdot\nabla)u+\nabla p-\nu\Delta u.
\]

Получаемая цепочка имеет форму:

```text
∇·u = 0
∂t u = (0, 0, 0)
(u·∇)u = (-x, -y, 0)
∇p = (x, y, 0)
Δu = (0, 0, 0)
R = (0, 0, 0)
```

Таким образом, сценарий сертифицирует точную структурную идентичность выбранного гладкого поля в системе Навье—Стокса.

## Добавленные типовые функции

| API | Назначение |
|---|---|
| `RicisVectorField3` | Три независимые отложенные компоненты поля `U,V,W`. |
| `PartialDerivative` | Точная символьная частная производная по `X`, `Y`, `Z` или `T`. |
| `Gradient` | Пространственный градиент scalar-поля. |
| `Divergence` | Дивергенция векторного поля. |
| `Laplacian` | Покомпонентный пространственный лапласиан. |
| `TimeDerivative` | Покомпонентная производная по времени. |
| `ConvectiveDerivative` | Поле `(u·∇)v`. |
| `ProveNavierStokesIdentity` | Документирует NS-01–NS-07 и возвращает proof-сертификат только при точном нулевом остатке. |

## QA: найденные и закрытые пробелы

| ID | Найденный случай | Исправление | Регрессия |
|---|---|---|---|
| NS-QA-01 | Правило производной создавало обычный коэффициент `F·0`, который преждевременно становился мостом `0_F`. | Локальная finite-редукция сворачивает доказанные нулевые коэффициенты до применения O(1). | NS01 |
| NS-QA-02 | Давление давало `0.5·(2·x)` вместо `x`, что скрывало сокращение остатка. | Добавлено точное объединение повторных слагаемых и вложенных конечных коэффициентов. | NS02, NS03 |
| NS-QA-03 | Вложенный консольный проект попадал в компиляцию `Ricis.Core` через собственный `obj`-каталог. | Добавлено явное исключение `Ricis.NavierStokes.Console/**/*.cs` из библиотеки. | Полная сборка решения |
| NS-QA-04 | Стационарная производная печатала артефакт `-0`. | Ноль канонизируется в положительный typed zero. | NS06 |

Полный регрессионный набор включает NS01–NS06 наряду с существующими правилами RICIS.

## Граница сценария

Сценарий является строго символическим proof-стендом для заявленного гладкого поля. Он не выполняет численной дискретизации, подбора решения, пределов или правила Лопиталя. Расширение класса сертифицируемых полей выполняется через те же типовые операции и обязательные регрессии NS-серии.
