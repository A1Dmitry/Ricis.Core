# Аналитический математический сахар RICIS

## Назначение

`RicisAnalyticExtensions` предоставляет компактный API для построения аналитических функций из отложенных `Expression<Func<double,double>>`. Он не вычисляет входную функцию при создании результата: каждый метод сначала нормализует исходную лямбду обычным RICIS-конвейером, затем создаёт явный `Math.*` узел и снова нормализует итоговое дерево.

> Это слой синтаксического сахара для expression tree, а не новая аксиома RICIS. Пределы, Лопиталь, численные разности и скрытый вызов делегата не применяются.

| API | Строимое expression tree |
|---|---|
| `F.Sin()`, `F.Cos()`, `F.Tan()` | `Math.Sin(F)`, `Math.Cos(F)`, `Math.Tan(F)` |
| `F.Sinh()`, `F.Cosh()`, `F.Tanh()` | Соответствующие гиперболические узлы `Math.*` |
| `F.Exp()` | `Math.Exp(F)` |
| `F.Log()`, `F.Log10()` | `Math.Log(F)`, `Math.Log10(F)` |
| `F.Sqrt()` | `Math.Sqrt(F)` |
| `F.Pow(p)` | `Math.Pow(F,p)` с постоянным показателем |
| `F.Pow(G)` | `Math.Pow(F,G)` с отложенным показателем |

## Совместимость с RICIS

Входная функция нормализуется до создания `Math.*` узла. Поэтому `Exp(x/x)` строится из нормализованного `Exp(1)` и остаётся исполнимым в классической нулевой точке `x=0`. Постоянная тригонометрия затем обрабатывается существующей полярной фазой, а сингулярности, появляющиеся в производных, проходят обычные мосты O(1) и правила RICIS.

Все unary-узлы и `Pow` с постоянным показателем непосредственно поддержаны формальной производной `DxDt()`: применяются точные структурные правила и цепное правило. Для `Pow(F,G)` с отложенным показателем построение выражения поддерживается, однако его формальная производная пока остаётся отложенным узлом, пока не будет принят отдельный нормативный контракт для общего правила `d(F^G)`.

## Консоль и регрессии

```bash
dotnet run --project Ricis.Console/Ricis.Console.csproj -c Release -- --analytic-demo
```

Регрессии `AN01`–`AN06` фиксируют форму тригонометрических и гиперболических узлов, значения exp/log/log10/sqrt, совместимость `Pow(F,constant)` с `DxDt`, привязку отложенного показателя и L1-нормализацию входа.
